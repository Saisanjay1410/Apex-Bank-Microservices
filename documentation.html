1. System Architecture & Topology

The system is built as a distributed, service-oriented architecture consisting of five backend Spring Boot services, an Apache Kafka messaging broker, a central MySQL database, and a high-performance single-page application (SPA) built with React and Vite.

Microservice Port Application ID Role & Key Responsibilities
Eureka Server :8761 eureka-server Central service registry and heartbeat coordinator for dynamic discovery.
API Gateway :8090 api-gateway Spring Cloud Gateway (Reactive WebFlux) routing requests to services via Eureka.
Banking Service :8081 banking-service Core banking: JWT auth, bank accounts, audit ledger, and transactions.
Payroll Service :8082 payroll-service Enterprise payroll management with Kafka asynchronous event streaming.
AI Chatbot Service :8083 ai-chatbot AI financial assistance resolving natural-language operations queries.
Vite Frontend :5173 frontend Modular client SPA with dual Light/Dark themes and Live/Mock fallback modes.
MySQL Database :3306 banking_payroll ACID relational storage for users, roles, accounts, transactions, and staff.

3. Technologies Used Across the Stack

A. Frontend Application (Directory: c:\Users\saisa\Desktop\Poc Implemented\frontend)

  • React 19 & TypeScript: Component modularity, strict typing, and high rendering efficiency.
  • Vite 8.3 Bundler: Native ESM-powered development server with instant HMR and production rollups.
  • TanStack React Query v5: Server-state synchronization, automatic caching, garbage collection, and optimistic mutation rollbacks.
  • Zustand: Lightweight global client state for auth tokens, demo role switching, theme preference, and mock fallback toggling.
  • React Router v7: Declarative client routing with protected routes and role-based redirect guards.
  • Axios: Robust HTTP client with automatic JWT Bearer token request interceptor and error status handling.
  • Pure Vanilla CSS Design System: Complete dual-theme architecture (Modern Fintech Light + Obsidian Dark) inspired by Stripe and Mercury Bank, with 0% heavy CSS framework overhead.
  • Lucide React: Clean, crisp vector iconography.

B. Backend Microservices

  • Java 21 / 24 & Spring Boot 4.1.0: High-throughput reactive and servlet runtimes.
  • Spring Cloud 2025.1.2: Microservices coordination, client-side load balancing, and dynamic routing.
  • Netflix Eureka Server & Client: Dynamic service registration, heartbeat validation, and instance cataloging.
  • Spring Cloud Gateway (WebFlux): Asynchronous reverse proxy and request forwarding to Eureka instances.
  • Spring Security 6 & JJWT: Stateless authentication with HMAC-SHA256 encrypted JWT Bearer tokens (1-hour validity).
  • Spring Data JPA & Hibernate: Relational object-relational mapping, transactional integrity, and automated schema validation.
  • MySQL 8.0 Community Server: Transactional relational database engine running under Windows Service MYSQL80.
  • Apache Kafka: Distributed event streaming bus for asynchronous inter-service workflows.
  • SpringDoc OpenAPI / Swagger UI: Interactive API schema exploration and documentation.

Content-Type: application/json

Request:
{
  "email": "admin@bank.com",
  "password": "Admin@123"
}

Response (200 OK):
{
  "token": "eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJhZG1pbiIsInJvbGUiOiJST0xFX0FETUlOIi... [JWT TOKEN]"
}

2. Register New User (Public)

POST http://localhost:8081/auth/register
Content-Type: application/json

Request:
{
  "username": "alex_fintech",
  "email": "alex@bank.com",
  "password": "Password123!"

"User registered successfully"

POST http://localhost:8081/auth/create-hr

{
  "username": "hr_lead",

"HR user created successfully"

B. Bank Account Endpoints (Banking Service — Port 8081)

Requires Authorization: Bearer <TOKEN> (Roles: ADMIN, EMPLOYEE)

Method URL Description
GET http://localhost:8081/accounts List all active bank accounts from MySQL.
GET http://localhost:8081/accounts/{id} Fetch a single account by primary key ID.
POST http://localhost:8081/accounts Open a new bank account.
PUT http://localhost:8081/accounts/{id} Update account details or associated employee ID.
DELETE http://localhost:8081/accounts/{id} Close an account (only allowed if it has 0 transactions).

Sample Account Creation Request (POST /accounts):

POST http://localhost:8081/accounts
Authorization: Bearer <TOKEN>
Content-Type: application/json

{
  "accountNumber": "ACC10003",
  "accountType": "SAVINGS",
  "balance": 15000.00,
  "employeeId": 1
}

C. Transaction Endpoints (Banking Service — Port 8081)

Requires Authorization: Bearer <TOKEN> (Roles: ADMIN, EMPLOYEE)

Method URL Description
GET http://localhost:8081/transactions Retrieve the full financial audit ledger from MySQL.
GET http://localhost:8081/transactions/{id} Fetch single transaction details.
POST http://localhost:8081/transactions Execute deposit/withdrawal; automatically increments/decrements account balance.
DELETE http://localhost:8081/transactions/{id} Delete an audit entry from ledger.

Sample Transaction Request (POST /transactions):

POST http://localhost:8081/transactions
Authorization: Bearer <TOKEN>
Content-Type: application/json

{
  "accountId": 2,
  "amount": 1250.00,
  "transactionType": "DEPOSIT",
  "remarks": "Executive Q3 Bonus Allocation"
}

D. Staff & Employee Endpoints (Banking Service — Port 8081)

Requires Authorization: Bearer <TOKEN> (Roles: ADMIN, HR)

Method URL Description
GET http://localhost:8081/employees List all staff members and payroll records.
GET http://localhost:8081/employees/{id} Fetch employee profile by ID.
POST http://localhost:8081/employees Add a new staff record.
PUT http://localhost:8081/employees/{id} Update employee designation, department, or salary.
DELETE http://localhost:8081/employees/{id} Remove employee record.

6. Step-by-Step Guide: How to Run Frontend & Backend

Prerequisites: Ensure you have Java 21 or 24 (java -version), Maven 3.9+ (mvn -v), Node.js 18+ (node -v), and MySQL 8.0 installed.
1 Verify MySQL Database Service

Ensure that MySQL is running on port 3306 with database banking_payroll:

# Check MySQL Windows service
Get-Service *mysql*

# Verify tables exist
mysql -u root -p"Sanjay@2004" -e "USE banking_payroll; SHOW TABLES;"
2 Start Eureka Discovery Server (Port 8761)

Always start Eureka Server first so microservices can register immediately on boot:

cd "c:\Users\saisa\Desktop\Poc Implemented\Eureka-Server"
mvn spring-boot:run

Verify in browser: Open http://localhost:8761 to see the Eureka Dashboard.

3 Start Banking Service (Port 8081)

Runs the core banking ledger, JWT auth, and MySQL data access:

cd "c:\Users\saisa\Desktop\Poc Implemented\Banking-Service"
mvn spring-boot:run
4 Start Payroll Service (Port 8082)

Runs employee payroll management and registers with Eureka:

cd "c:\Users\saisa\Desktop\Poc Implemented\Payroll-Service"
mvn spring-boot:run
5 Start AI Chatbot Service (Port 8083)

Runs the AI conversational assistant service:

cd "c:\Users\saisa\Desktop\Poc Implemented\AI-Chatbot_Geethika"
mvn spring-boot:run
6 Start Spring Cloud API Gateway (Port 8090)

Provides unified reactive proxying and dynamic routing to Eureka instances:

cd "c:\Users\saisa\Desktop\Poc Implemented\API-Gateway"
mvn spring-boot:run

(Note: Configured to port 8090 to avoid collision with Oracle TNS Listener on port 8080).

7 Start Vite React Frontend (Port 5173)

Launch the React single-page portal:

cd "c:\Users\saisa\Desktop\Poc Implemented\frontend"
npm install    # (First time only)
npm run dev

Open http://localhost:5173 in any web browser!

7. Testing & Verification Checklist

  1. Open Portal: Navigate to http://localhost:5173/login.
  2. Ensure Live Mode: Verify the top badge displays Live Backend (:8081). (If it displays Mock Mode, click it once to switch).
  3. Sign In as Admin: Click Admin shortcut button (or enter admin@bank.com / Admin@123).
  4. Verify Real MySQL Data:
